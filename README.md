# صفحة طلب جاكيت التخرج

صفحة يدخلها الطالب الخريج فيرى ظهر الجاكيت، ويكتب الاسم أو الختم بخط Foda، ويختار المقاس (S–XXL)، ثم يرسل الطلب.
لوحة المدير (`admin.html`) لمراجعة الطلبات واعتمادها أو طلب تعديل الاسم عبر واتساب. الطلبات تُحفظ في Google Sheets.

خطوات الإعداد والنشر: [DEPLOY.md](DEPLOY.md)
